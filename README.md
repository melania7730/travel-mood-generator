# 🌍 AI Travel Mood Generator

An AI-powered web app that generates dreamy travel moods based on destinations or atmospheres entered by the user.

## ✨ Features

- AI-generated travel moods
- Custom destination or mood input
- Animated loading state
- Responsive and aesthetic UI
- Built with HTML, CSS, JavaScript, and SheCodes AI API
